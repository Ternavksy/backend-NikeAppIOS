# Nike Backend (Go)

Backend-сервер на **Go** для мобильного приложения  
👉 **NikeAppIOS**: https://github.com/Ternavksy/NikeAppIOS

Проект был создан для:
- отдачи **JSON API** с товарами
- раздачи **изображений** через HTTP
- использования вместе с **ngrok** для доступа с iOS-приложения

---

## 🚀 Назначение проекта

Этот backend используется как простой HTTP-сервер, который:
- возвращает список товаров по эндпоинту `/products`
- раздаёт изображения из локальной папки `/images`
- позволяет iOS-приложению получать картинки через публичный URL (ngrok)

Проект не использует БД — данные хранятся **в коде**, что упрощает разработку и тестирование.

---

## 🛠 Технологии

- Go
- net/http
- JSON API
- FileServer (раздача статических файлов)
- ngrok

## 📦 Установка и запуск

### 1. Клонировать репозиторий
```bash ```
git clone https://github.com/your-username/nike-backend.git
cd nike-backend

### 2. Запустить сервер

go run main.go

## 🌐 API эндпоинты

GET /products Возвращает список товаров в формате JSON.

## 🌍 Использование с ngrok

Для доступа к серверу из iOS-приложения используется ngrok.

### Запуск ngrok: 
ngrok http 8080
ngrok выдаст публичный URL, например: https://abcd-1234.ngrok-free.app
Этот URL используется в NikeAppIOS.

## 📱 Связь с iOS-приложением

Backend используется мобильным приложением:

- для загрузки списка товаров

- для отображения изображений товаров

- для тестирования сетевого слоя без реального продакшн-сервера
